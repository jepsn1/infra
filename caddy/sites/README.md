# Caddy site configs

One `<app>.caddy` file per application. Generated by `scripts/new-app.sh`, or by hand:

```caddy
app.example.com {
	reverse_proxy <container-name>:<port>
}
```

The container must be on the `web` Docker network. Reload after changes:

```bash
/srv/infra/scripts/caddy-reload.sh
```
